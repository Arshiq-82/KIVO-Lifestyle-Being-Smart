KIVO WhatsApp Catalogue Website

FILES
- index.html: page structure
- styles.css: responsive light-theme styling
- script.js: product catalogue and WhatsApp links
- logo.svg: simple editable vector logo

BEFORE PUBLISHING
1. Open script.js.
2. Replace WHATSAPP_NUMBER = "91XXXXXXXXXX" with your WhatsApp Business number.
   Format: country code + number, digits only. Example: 919876543210.
3. Replace the four demo products, prices, descriptions and image URLs with verified listings.
4. The current prices and products are placeholders for layout demonstration, not confirmed offers.
5. Check every WhatsApp button on desktop and mobile.

DEPLOY
- Create a Netlify account.
- Drag the folder (or upload its ZIP) into Netlify Drop / deploy flow.
- Connect a custom domain later if desired.
- GitHub can be used as the source-code repository; use Netlify for hosting this commercial catalogue.

IMPORTANT
- This is a catalogue, not a checkout or payment system.
- Customers initiate an enquiry on WhatsApp. Confirm stock, final price, shipping, delivery ETA and return terms before collecting payment.
- Publish clear contact, privacy, shipping, cancellation, refund and return policies before taking orders.
- Verify supplier product claims, certifications and import compliance before advertising.
